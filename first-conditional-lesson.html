Grammar lesson

First Conditional: If + will

The rule

If + present simple,will + base verb

If we plant flowers, more bees will come.

القاعدة: بعد if نستخدم المضارع البسيط، وفي جملة النتيجة نستخدم will + الفعل (المصدر).

مثال: إذا زرعنا الأزهار، سيأتي المزيد من النحل.

The trick: if and will never sit together!

The if half has no will. The result half has will.

الحيلة: if و will لا يجلسان معاً! نصف if بدون will، ونصف النتيجة فيه will.

Four common mistakes

If it will rain, we will stay inside.

If it rains, we will stay inside.

No will after if.

لا نكتب will بعد if.

If she come, I will help her.

If she comes, I will help her.

With he / she / it, add s.

مع he / she / it نضيف s.

We will played outside.

We will play outside.

After will, use the base verb only.

بعد will نستخدم المصدر فقط (بدون s أو ed أو to).

If it rains, we don’t play.

If it rains, we won’t play.

The result is in the future: use won’t + base verb.

النتيجة في المستقبل، فنستخدم won’t + المصدر.

Quick check: 3 steps

  1. Is there a will in the if half? Take it out.
    هل في نصف if كلمة will؟ احذفيها.
  2. Did you add s with he / she / it?
    هل أضفتِ s مع he / she / it؟
  3. Is the verb after will a base verb?
    هل الفعل بعد will في صورة المصدر؟
